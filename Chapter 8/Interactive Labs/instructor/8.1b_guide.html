RGB colors and a recursive fractal: the c-curve poster

Objectives

  • Generate random RGB colors whose components stay within 0 to 255
  • Complete the recursive c-curve algorithm from its base case and recursive step
  • Predict how many lines a fractal of a given level draws, and confirm it with a recursive count

Requirements

  1. R1 randomColor() returns a tuple of three random integers, each from 0 to 255 inclusive.
  2. R2 In the base case (level 0), cCurve sets the pen to a new randomColor() before drawing its line.
  3. R3 In the recursive step, cCurve computes xm = (x1 + x2 + y1 - y2) // 2 and ym = (x2 + y1 + y2 - x1) // 2, then draws two c-curves of level - 1: from (x1, y1) to (xm, ym), and from (xm, ym) to (x2, y2).
  4. R4 countLines(level) returns the number of lines a c-curve of that level draws, using recursion (1 at level 0) and without drawing anything.
  5. R5 The test program's line counts, traced endpoints and color checks match. (verified by the program output)

Before you code: warm-up and model answers

  1. The starter's randomColor uses random.randint(0, 256). How many different values can each call return, and which of them is not a valid RGB component?

    257 values, 0 through 256, because randint includes both ends. 256 is invalid: each component is 8 bits, which holds 256 values, 0 to 255.

  2. Using the formulas, compute (xm, ym) for a level-1 c-curve from (50, -50) to (50, 50). What shape do the two new lines make?

    xm = (50 + 50 + (-50) - 50) // 2 = 0 and ym = (50 + (-50) + 50 - 50) // 2 = 0, so the corner is (0, 0). The lines (50, -50) to (0, 0) and (0, 0) to (50, 50) meet at a right angle, like a V on its side.

penturtle.py (read-only for students)
"""penturtle.py - a text-mode stand-in for turtle.Turtle.

It has the same method names as the Turtle methods in Table 8-2, so code
you write with it also runs in IDLE: change the import to
    from turtle import Turtle
Instead of opening a window, this Turtle keeps a log of the lines it draws.

Extras for the labs (NOT in the real Turtle):
    t.lines(), t.lineColors(), t.report()
"""
import math


def _tidy(value):
    """Rounds to 2 decimals and turns -0.0 into 0.0."""
    return round(value, 2) + 0.0


def _checkColor(args):
    """Returns the color given to pencolor/fillcolor, or raises ValueError."""
    if len(args) == 1 and isinstance(args[0], str):
        return args[0]
    if len(args) == 1 and isinstance(args[0], tuple):
        args = args[0]
    if len(args) != 3:
        raise ValueError("a color is a string or three RGB values, got " +
                         repr(args))
    for part in args:
        if not isinstance(part, int) or part < 0 or part > 255:
            raise ValueError("bad color sequence: " + repr(tuple(args)) +
                             " (each RGB component is an int from 0 to 255)")
    return tuple(args)


class _Screen:
    """The turtle's window: 300 by 200 pixels, as in the book's turtle.cfg."""

    def __init__(self):
        self._bg = "white"

    def window_width(self):
        return 300

    def window_height(self):
        return 200

    def bgcolor(self, *color):
        if not color:
            return self._bg
        self._bg = _checkColor(color)

    def colormode(self, mode=None):
        return 255


class Turtle:
    """A turtle that logs its lines instead of drawing them in a window."""

    def __init__(self):
        self._x = 0.0
        self._y = 0.0
        self._heading = 0.0
        self._down = True
        self._color = "black"
        self._fill = "black"
        self._width = 1
        self._visible = True
        self._filling = False
        self._lines = []
        self.screen = _Screen()

    # ---- accessor methods: report the state, change nothing ----
    def position(self):
        """Returns the current position (x, y)."""
        return (_tidy(self._x), _tidy(self._y))

    pos = position

    def xcor(self):
        return _tidy(self._x)

    def ycor(self):
        return _tidy(self._y)

    def heading(self):
        """Returns the current direction in degrees (0 east, 90 north)."""
        h = _tidy(self._heading % 360)
        return 0.0 if h == 360 else h

    def isdown(self):
        """Returns True if the pen is down."""
        return self._down

    def isvisible(self):
        return self._visible

    # ---- mutator methods: change the state ----
    def up(self):
        self._down = False

    penup = pu = up

    def down(self):
        self._down = True

    pendown = pd = down

    def setheading(self, degrees):
        self._heading = float(degrees)

    seth = setheading

    def left(self, degrees):
        self._heading += degrees

    lt = left

    def right(self, degrees):
        self._heading -= degrees

    rt = right

    def goto(self, x, y=None):
        if y is None:
            (x, y) = x
        self._moveTo(float(x), float(y))

    setpos = setposition = goto

    def forward(self, distance):
        angle = math.radians(self._heading)
        self._moveTo(self._x + distance * math.cos(angle),
                     self._y + distance * math.sin(angle))

    fd = forward

    def backward(self, distance):
        self.forward(-distance)

    back = bk = backward

    def home(self):
        self.goto(0, 0)
        self.setheading(0)

    def pencolor(self, *color):
        if not color:
            return self._color
        self._color = _checkColor(color)

    def fillcolor(self, *color):
        if not color:
            return self._fill
        self._fill = _checkColor(color)

    def width(self, pixels=None):
        if pixels is None:
            return self._width
        self._width = pixels

    pensize = width

    def begin_fill(self):
        self._filling = True

    def end_fill(self):
        self._filling = False

    def clear(self):
        """Erases the drawings; the turtle's state does not change."""
        self._lines = []

    def hideturtle(self):
        self._visible = False

    ht = hideturtle

    def showturtle(self):
        self._visible = True

    st = showturtle

    def speed(self, value=None):
        return 0

    def shape(self, name=None):
        return "classic"

    def _moveTo(self, x, y):
        start = (_tidy(self._x), _tidy(self._y))
        end = (_tidy(x), _tidy(y))
        if self._down and start != end:
            self._lines.append((start, end, self._color))
        self._x = x
        self._y = y

    # ---- extras for the labs (not in the real Turtle) ----
    def lines(self):
        """Returns the lines drawn so far as a list of (start, end) points."""
        return [(start, end) for (start, end, color) in self._lines]

    def lineColors(self):
        """Returns the pen color of each line drawn so far."""
        return [color for (start, end, color) in self._lines]

    def report(self):
        """Returns a short summary of the drawing."""
        total = 0.0
        for ((x1, y1), (x2, y2), color) in self._lines:
            total += math.hypot(x2 - x1, y2 - y1)
        return ("Lines drawn: " + str(len(self._lines)) + ", total length " +
                str(_tidy(total)) + " pixels")

Solution

ccurve.py
"""ccurve.py - draw a c-curve fractal, each line in a random color."""
import random
from penturtle import Turtle   # in IDLE: from turtle import Turtle


def randomColor():
    """Returns a random RGB color as a tuple of three integers."""
    return (random.randint(0, 255), random.randint(0, 255),
            random.randint(0, 255))


def cCurve(t, x1, y1, x2, y2, level):
    """Draws a c-curve of the given level from (x1, y1) to (x2, y2)."""

    def drawLine(x1, y1, x2, y2):
        """Draws a line segment between the endpoints."""
        t.up()
        t.goto(x1, y1)
        t.down()
        t.goto(x2, y2)

    if level == 0:
        t.pencolor(randomColor())
        drawLine(x1, y1, x2, y2)
    else:
        xm = (x1 + x2 + y1 - y2) // 2
        ym = (x2 + y1 + y2 - x1) // 2
        cCurve(t, x1, y1, xm, ym, level - 1)
        cCurve(t, xm, ym, x2, y2, level - 1)


def countLines(level):
    """Returns how many lines a c-curve of the given level draws,
    without drawing it."""
    if level == 0:
        return 1
    else:
        return 2 * countLines(level - 1)


def main():
    """Asks for a level, draws the c-curve and reports the drawing."""
    level = int(input("Enter the level (0 or greater): "))
    t = Turtle()
    t.hideturtle()
    cCurve(t, 50, -50, 50, 50, level)
    print(t.report())
    print("countLines predicted", countLines(level))


if __name__ == "__main__":
    main()

Walkthrough

random.randint(a, b) includes both ends, so randint(0, 256) can return 256, one more than an 8-bit component can hold (random.randrange(256) is an equivalent fix). The base case draws exactly one line in a fresh color; because every line of the fractal is drawn by some level-0 call, every line gets its own color. The recursive step is the case study's pseudocode: the two formulas find the corner where two half-length segments meet at a right angle. Since each level replaces every line with two, a level-N curve has 2 * (lines at level N - 1), which is 2 ** N: countLines mirrors the shape of cCurve but returns a number instead of drawing. In IDLE the real turtle needs colormode = 255 (the book's turtle.cfg) or t.screen.colormode(255) to accept RGB integers.

Messages students see when a check fails

C1 · components range from 0 to 255

random.randint(a, b) includes both a and b. An RGB component goes from 0 to 255 (8 bits, 256 values), so use random.randint(0, 255) for each of the three.

C2 · a new random pen color per line

In the level == 0 branch, call t.pencolor(randomColor()) before drawLine. Each level-0 call draws exactly one line, so this gives every line its own color.

C3 · the corner point formulas

Compute the corner with the case study's formulas: xm = (x1 + x2 + y1 - y2) // 2 and ym = (x2 + y1 + y2 - x1) // 2.

C4 · two recursive calls at level - 1

Draw the two halves in order: cCurve(t, x1, y1, xm, ym, level - 1), then cCurve(t, xm, ym, x2, y2, level - 1). Passing level - 1 moves each call toward the base case.

C5 · countLines is recursive

Give countLines the same shape as cCurve: a base case (level == 0 returns 1) and a recursive step that uses countLines(level - 1). It should count, not draw.

Progressive hints

  1. For R1, check the documentation of random.randint(a, b): is b one of the values it can return?

  2. A level-0 call is the only place a line is drawn. If the pen color changes right there, how many lines share a color?

  3. For countLines: a level-1 curve is two level-0 curves. A level-2 curve is two level-1 curves. Write that sentence as a return statement.

Reflection: questions and model answers

  1. Explain, using the structure of cCurve, why a level-N c-curve draws 2 ** N lines. How many lines does a level-10 curve draw?

    Every call above level 0 makes exactly two calls one level lower and draws nothing itself, so the number of level-0 calls doubles at each level. Only level-0 calls draw, one line each, giving 2 N lines. A level-10 curve draws 2 10 = 1024 lines.

  2. The case study turns off animation with tracer(False) for levels above 8. Using your line counts, explain why.

    The number of lines doubles with each level, so level 9 already draws 512 lines and level 12 draws 4096. Animating each line would take a long time, so the program builds the whole drawing in memory and shows it once with update().

  3. How many bits does one RGB color take, and how many different colors could randomColor return?

    Three components of 8 bits each, 24 bits in total. Each component has 256 values, so there are 256 * 256 * 256 = 16,777,216 colors, which is 2 ** 24.

Write curveLength(level) that returns the total length of a c-curve from (50, -50) to (50, 50) without drawing it. Each level multiplies the length of every line by 1 / sqrt(2) and doubles the number of lines. Compare its answer for level 3 with t.report() after Run.
