COP1035 · Python Programming · Lab 8.2b

New images from old: the newspaper's photo thumbnails

Objectives

  • Use clone to build a new image while reading from an unchanged original
  • Average a pixel with its four neighbors, keeping the traversal away from the edges
  • Shrink an image by a factor so that every pixel of the new image receives a color

Requirements

  1. R1 blur builds its result in image.clone(), reads every pixel from the original image, writes only into the copy, and returns the copy. The argument image does not change.
  2. R2 Each blurred pixel is the average of five pixels: itself and its left, right, upper and lower neighbors (each component divided by 5 with //). Edge pixels keep their color.
  3. R3 shrink(image, factor) gives every pixel of the new image a color: the pixel at (newX, newY) copies the original pixel at (newX * factor, newY * factor).
  4. R4 The test program's blurred values and thumbnails match, with no blank pixels and the original photo unchanged. (verified by the program output)

Before you code: warm-up and model answers

  1. Trace the starter's shrink on a 4-by-4 photo with factor 2: which values does range(0, height - factor, factor) produce, and which pixels of the 2-by-2 thumbnail get a color?

    range(0, 2, 2) produces only 0, for both loops. So only the thumbnail pixel (0, 0) gets a color; (1, 0), (0, 1) and (1, 1) stay blank, 3 blank pixels.

  2. blur loops from 1 to getHeight() - 2 and from 1 to getWidth() - 2. Why doesn't it start at 0?

    A pixel on the edge is missing at least one neighbor: at x = 0 there is no left neighbor, so getPixel(x - 1, y) would be outside the image. Skipping the outer edge avoids checking bounds for every neighbor, at the cost of leaving the edge pixels unblurred.

thumbs.py
"""thumbs.py - soften and shrink photos for the campus newspaper's website."""
from images import Image   # the real images module has the same Image methods


def tripleSum(triple1, triple2):
    """Returns the sums of two RGB tuples, position by position."""
    (r1, g1, b1) = triple1
    (r2, g2, b2) = triple2
    return (r1 + r2, g1 + g2, b1 + b2)


def blur(image):
    """Builds and returns a new image which is a blurred copy of the
    argument image. The argument image must not change."""
    # TODO (R1): build the result in a copy, and read every pixel from
    # the original.
    for y in range(1, image.getHeight() - 1):
        for x in range(1, image.getWidth() - 1):
            oldP = image.getPixel(x, y)
            # TODO (R2): add the pixel and its 4 neighbors (left, right,
            # above, below) with tripleSum, then divide each sum by 5.
            image.setPixel(x, y, oldP)
    return image


def shrink(image, factor):
    """Builds and returns a new image which is a smaller copy of the argument
    image, by the factor argument."""
    width = image.getWidth()
    height = image.getHeight()
    new = Image(width // factor, height // factor)
    # TODO (R3): on a 4-by-4 photo with factor 2, this leaves blank
    # pixels in the new image. Every pixel of the new image must get
    # a color.
    newY = 0
    for oldY in range(0, height - factor, factor):
        newX = 0
        for oldX in range(0, width - factor, factor):
            new.setPixel(newX, newY, image.getPixel(oldX, oldY))
            newX += 1
        newY += 1
    return new


def samplePhoto():
    """Returns a small 4-by-4 test photo with a bright square in the middle."""
    dark = (20, 40, 60)
    lit = (220, 200, 180)
    return Image([[dark, dark, dark, dark],
                  [dark, lit, lit, dark],
                  [dark, lit, lit, dark],
                  [dark, dark, dark, dark]])


def main():
    """Shows a photo, its blurred copy and its thumbnail."""
    photo = samplePhoto()
    photo.draw()
    print("Blurred:")
    blur(photo).draw()
    print("Thumbnail, factor 2:")
    thumb = shrink(photo, 2)
    thumb.draw()
    print("Blank pixels in the thumbnail:", thumb.blankPixels())


if __name__ == "__main__":
    main()
images.py (read-only for students)
"""images.py - a text-mode stand-in for the book's images module.

The Image class has the same methods as Table 8-4 (getWidth, getHeight,
getPixel, setPixel, clone, draw, save), so functions you write with it also
run with the real images module. Two differences:
  - Build an image from rows of RGB tuples, Image(rows), instead of a GIF file
    (Image(width, height) still makes a blank image, as in the book).
  - draw() prints the pixels instead of opening a window; a blank (transparent)
    pixel prints as  --  .
Extra for the labs (NOT in the real module): image.blankPixels().
"""


class Image:
    """A grid of RGB pixels with (0, 0) at the upper-left corner."""

    def __init__(self, *args):
        self.filename = ""
        if len(args) == 2 and all(isinstance(a, int) for a in args):
            (width, height) = args
            self._pixels = [[None] * width for y in range(height)]
        elif len(args) == 1 and isinstance(args[0], list):
            self._pixels = [list(row) for row in args[0]]
            for row in self._pixels:
                for p in row:
                    _checkRGB(p)
        else:
            raise ValueError("this stand-in builds Image(width, height) or "
                             "Image(rows); it cannot open image files")

    def getWidth(self):
        """Returns the width in pixels."""
        return len(self._pixels[0]) if self._pixels else 0

    def getHeight(self):
        """Returns the height in pixels."""
        return len(self._pixels)

    def getPixel(self, x, y):
        """Returns the (r, g, b) tuple at column x, row y."""
        self._checkPosition(x, y)
        p = self._pixels[y][x]
        return (0, 0, 0) if p is None else p

    def setPixel(self, x, y, rgb):
        """Replaces the pixel at column x, row y with the tuple (r, g, b)."""
        self._checkPosition(x, y)
        _checkRGB(rgb)
        self._pixels[y][x] = tuple(rgb)

    def clone(self):
        """Returns a new image with the same pixels; changing one leaves
        the other alone."""
        copy = Image(self.getWidth(), self.getHeight())
        copy._pixels = [list(row) for row in self._pixels]
        return copy

    def draw(self):
        """Prints the pixels, one row per line (the real one opens a window)."""
        for row in self._pixels:
            cells = []
            for p in row:
                if p is None:
                    cells.append("     --     ")
                else:
                    cells.append("(%3d,%3d,%3d)" % p)
            print(" ".join(cells))

    def save(self, filename=None):
        """Records the filename (the real module writes a GIF file)."""
        if filename is not None:
            if not filename.endswith(".gif"):
                filename += ".gif"
            self.filename = filename

    def blankPixels(self):
        """Returns how many pixels have never been given a color."""
        return sum(row.count(None) for row in self._pixels)

    def __str__(self):
        return ("Filename: " + self.filename +
                "\nWidth: " + str(self.getWidth()) +
                "\nHeight: " + str(self.getHeight()))

    def _checkPosition(self, x, y):
        w = self.getWidth()
        h = self.getHeight()
        inside = (isinstance(x, int) and isinstance(y, int) and
                  0 <= x < w and 0 <= y < h)
        if not inside:
            raise IndexError("pixel (" + str(x) + ", " + str(y) +
                             ") is outside this " + str(w) + " x " + str(h) +
                             " image: x goes 0 to " + str(w - 1) +
                             ", y goes 0 to " + str(h - 1))


def _checkRGB(rgb):
    """Raises ValueError unless rgb is three ints from 0 to 255."""
    if not (isinstance(rgb, tuple) and len(rgb) == 3 and
            all(isinstance(c, int) and 0 <= c <= 255 for c in rgb)):
        raise ValueError("a pixel is a tuple of three ints from 0 to 255, "
                         "got " + repr(rgb))

Solution

thumbs.py
"""thumbs.py - soften and shrink photos for the campus newspaper's website."""
from images import Image   # the real images module has the same Image methods


def tripleSum(triple1, triple2):
    """Returns the sums of two RGB tuples, position by position."""
    (r1, g1, b1) = triple1
    (r2, g2, b2) = triple2
    return (r1 + r2, g1 + g2, b1 + b2)


def blur(image):
    """Builds and returns a new image which is a blurred copy of the
    argument image. The argument image must not change."""
    new = image.clone()
    for y in range(1, image.getHeight() - 1):
        for x in range(1, image.getWidth() - 1):
            oldP = image.getPixel(x, y)
            left = image.getPixel(x - 1, y)
            right = image.getPixel(x + 1, y)
            top = image.getPixel(x, y - 1)
            bottom = image.getPixel(x, y + 1)
            sums = tripleSum(oldP, left)
            sums = tripleSum(sums, right)
            sums = tripleSum(sums, top)
            sums = tripleSum(sums, bottom)
            (r, g, b) = sums
            new.setPixel(x, y, (r // 5, g // 5, b // 5))
    return new


def shrink(image, factor):
    """Builds and returns a new image which is a smaller copy of the argument
    image, by the factor argument."""
    new = Image(image.getWidth() // factor, image.getHeight() // factor)
    for newY in range(new.getHeight()):
        for newX in range(new.getWidth()):
            oldP = image.getPixel(newX * factor, newY * factor)
            new.setPixel(newX, newY, oldP)
    return new


def samplePhoto():
    """Returns a small 4-by-4 test photo with a bright square in the middle."""
    dark = (20, 40, 60)
    lit = (220, 200, 180)
    return Image([[dark, dark, dark, dark],
                  [dark, lit, lit, dark],
                  [dark, lit, lit, dark],
                  [dark, dark, dark, dark]])


def main():
    """Shows a photo, its blurred copy and its thumbnail."""
    photo = samplePhoto()
    photo.draw()
    print("Blurred:")
    blur(photo).draw()
    print("Thumbnail, factor 2:")
    thumb = shrink(photo, 2)
    thumb.draw()
    print("Blank pixels in the thumbnail:", thumb.blankPixels())


if __name__ == "__main__":
    main()

Walkthrough

blur must read from an image that doesn't change while it works: if it wrote into the image it reads, the pixel at (x, y) would be averaged with a left and upper neighbor that were already blurred, so the result would depend on the traversal order (the reading's Exercise 8-2, question 7). The traversal starts at 1 and stops before the last row and column, because edge pixels don't have four neighbors; the clone gives them their original colors. The reading combines the five tuples with reduce and divides with map and a lambda; repeated tripleSum calls, or summing the components by hand, are equivalent. In shrink, the starter's bound range(0, height - factor, factor) stops one block early whenever the size is a multiple of the factor (4 rows with factor 2 gives only row 0), and a while oldY < height - factor loop has the same problem. Driving the loops by the new image's size, as here, fills every new pixel and can never read outside the original. oldY <= height - factor is also correct.

Messages students see when a check fails

C1 · blur works in a clone

Start with new = image.clone(). The copy has the same pixels, and changing it leaves the original alone.

C2 · never writes into the original

Read with image.getPixel(...) and write with new.setPixel(...). Writing into image changes neighbors that later pixels still need to read, and destroys the newspaper's original.

C3 · returns the copy

Return the new image (for example return new), not the argument.

C4 · reads the four neighbors

Read the left (x - 1, y), right (x + 1, y), upper (x, y - 1) and lower (x, y + 1) neighbors. Remember that y grows downward in screen coordinates.

C5 · averages five pixels

Divide each summed component by 5 with //: the pixel plus its four neighbors. Integer division keeps every component an int.

C6 · the loop bounds reach the last block

A bound of height - factor stops one block early when the size is a multiple of the factor. Loop over the new image instead, for newY in range(new.getHeight()):, and compute the original position as newY * factor.

Reflection: questions and model answers

  1. Suppose blur wrote straight into the image it reads from. Which neighbors of pixel (2, 1) would already have changed by the time it is computed, and why does that give a wrong blur?

    The row-major traversal has already processed (1, 1), the left neighbor, and every pixel of row 0 above it is an edge that doesn't change. So the left neighbor would already be blurred, and the bright value would be smeared toward the right and down. The result depends on the traversal order instead of the original photo, which is why blur reads from the original and writes into a clone.

  2. Shrinking a 6-by-3 photo by 3 keeps 2 of its 18 pixels. What happens to the rest, and why does the reading say enlarging is the harder problem?

    16 of the 18 pixels are discarded; only every third pixel in each direction survives, so the information is lost for good. Shrinking only throws information away, and the eye rarely notices at a small size. Enlarging has to invent pixels that were never sampled, estimating their colors from neighbors, and the eye notices the loss of quality at the larger size.

  3. clone makes images that are structurally equivalent but not identical. What does that mean here, and what does soft is not photo check?

    The clone has the same width, height and pixel values, so the two images are equal in content, but they are two separate objects: changing a pixel in one doesn't change the other. soft is not photo checks identity, that blur returned a different object, rather than the same image modified.
