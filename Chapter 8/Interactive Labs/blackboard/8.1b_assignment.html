Lab 8.1b: RGB colors and a recursive fractal: the c-curve poster

Valid RGB values, random colors and the c-curve case study

Estimated time: about 35 minutes. Reading: Fundamentals of Python: First Programs, 3e (Lambert), Section 8.1, Colors and the RGB System, Example: Filling Radial Patterns with Random Colors, and Case Study 8-1: Recursive Patterns in Fractals, pp. 197-203.

You will be able to:

  • Generate random RGB colors whose components stay within 0 to 255
  • Complete the recursive c-curve algorithm from its base case and recursive step
  • Predict how many lines a fractal of a given level draws, and confirm it with a recursive count

How to complete it

  1. Open the lab page (8.1b.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (ccurve.py).

How it will be assessed

  • Requirements (4 pts): The code meets each requirement. The lab's checks are a guide; the code itself is also read.
  • Behaviour (3 pts): The test program's output matches the expected output.
  • Reflection (2 pts): Answers explain why, in your own words, using the reading's terms.
  • Code quality (1 pt): Readable names, consistent indentation, no leftover dead code.

The checks on the lab page give you feedback; they are not your grade.
