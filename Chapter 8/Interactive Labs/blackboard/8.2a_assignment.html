Lab 8.2a: Traversing a grid of pixels: student ID photo filters

Row-major traversal, tuple unpacking, grayscale and two-color posters

Estimated time: about 30 minutes. Reading: Fundamentals of Python: First Programs, 3e (Lambert), Section 8.2, The Properties of Images, The images Module, A Loop Pattern for Traversing a Grid, A Word on Tuples, Converting an Image to Black and White and Converting an Image to Grayscale, pp. 205-211.

You will be able to:

  • Visit every pixel of an image of any size with a row-major nested loop, using screen coordinates (x is the column, y is the row)
  • Unpack a pixel's (r, g, b) tuple, compute with its parts and set a new tuple
  • Convert to grayscale with luminance weights, and generalize black and white into a two-color filter

How to complete it

  1. Open the lab page (8.2a.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (filters.py).

How it will be assessed

  • Requirements (4 pts): The code meets each requirement. The lab's checks are a guide; the code itself is also read.
  • Behaviour (3 pts): The test program's output matches the expected output.
  • Reflection (2 pts): Answers explain why, in your own words, using the reading's terms.
  • Code quality (1 pt): Readable names, consistent indentation, no leftover dead code.

The checks on the lab page give you feedback; they are not your grade.
