Lab 8.1a: Objects, state and interface: the makerspace laser engraver

Mutator and accessor methods of a Turtle object

Estimated time: about 30 minutes. Reading: Fundamentals of Python: First Programs, 3e (Lambert), Section 8.1, Overview of Turtle Graphics, Turtle Operations, Object Instantiation and the turtle Module, Drawing Two-Dimensional Shapes and Examining an Object's Attributes, pp. 189-196.

You will be able to:

  • Use a Turtle object through its interface: instantiate it, then change its state with mutator methods
  • Generalize square and hexagon into one polygon function that works for any number of sides
  • Use accessor methods (position, heading, isdown) to save an object's state and restore it afterwards

How to complete it

  1. Open the lab page (8.1a.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (badges.py).

How it will be assessed

  • Requirements (4 pts): The code meets each requirement. The lab's checks are a guide; the code itself is also read.
  • Behaviour (3 pts): The test program's output matches the expected output.
  • Reflection (2 pts): Answers explain why, in your own words, using the reading's terms.
  • Code quality (1 pt): Readable names, consistent indentation, no leftover dead code.

The checks on the lab page give you feedback; they are not your grade.
