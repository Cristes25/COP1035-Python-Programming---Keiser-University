Lab 7.2a: Functions as data: the step-counter weekly report

Mapping and filtering

Estimated time: about 30 minutes. Reading: Fundamentals of Python: First Programs, 3e (Lambert), Section 7.2, Functions as First-Class Data Objects, Mapping, Filtering and Fail-Safe Programming, pp. 179-181 and 183-184.

You will be able to:

  • Pass a function as an argument to map and filter, without calling it
  • Write a predicate that returns a Boolean, and use it with filter to keep only the values that pass
  • Replace a loop that builds a list with a mapping, passing the map object straight to join as the reading does in changePerson

How to complete it

  1. Open the lab page (7.2a.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (steps.py).

How it will be assessed

  • Code meets every requirement (all structure checks pass) (6 pts): Check results in the lab report
  • Test program output matches (2 pts): Output section of the report
  • Warm-up and reflection answers explain the why, in the student's own words (2 pts): Answers in the report

The checks on the lab page give you feedback; they are not your grade.
