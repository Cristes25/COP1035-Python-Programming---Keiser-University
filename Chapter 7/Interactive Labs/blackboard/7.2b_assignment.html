Lab 7.2b: Reducing, lambda and a jump table: the club treasurer's tool

Functions on the fly, functions in a dictionary

Estimated time: about 35 minutes. Reading: Fundamentals of Python: First Programs, 3e (Lambert), Section 7.2, Reducing, Using lambda to Create Anonymous Functions, Creating Jump Tables and Fail-Safe Programming, pp. 181-184.

You will be able to:

  • Use functools.reduce with a lambda and an initial value, so the reducing also works on an empty list
  • Create a predicate on the fly with lambda and use it with filter
  • Replace a multiway selection statement with a jump table: a dictionary of functions keyed by command

How to complete it

  1. Open the lab page (7.2b.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (ledger.py).

How it will be assessed

  • Code meets every requirement (all structure checks pass) (6 pts): Check results in the lab report
  • Test program output matches (2 pts): Output section of the report
  • Warm-up and reflection answers explain the why, in the student's own words (2 pts): Answers in the report

The checks on the lab page give you feedback; they are not your grade.
