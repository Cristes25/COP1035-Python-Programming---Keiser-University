Lab 7.1a: Base case and recursive step: the pyramid workout planner

From a loop to a recursive function

Estimated time: about 30 minutes. Reading: Fundamentals of Python: First Programs, 3e (Lambert), Section 7.1, Defining a Recursive Function, Recursive Algorithms and Infinite Recursion, pp. 165-170.

You will be able to:

  • Convert a while loop into a recursive function by replacing the loop with a selection statement and the update with a recursive call
  • Write a recursive function that returns a value, with a base case that ends the recursion
  • Make sure every recursive step moves the argument toward the base case, so the recursion can't run forever

How to complete it

  1. Open the lab page (7.1a.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (pyramid.py).

How it will be assessed

  • Code meets every requirement (all structure checks pass) (6 pts): Check results in the lab report
  • Test program output matches (2 pts): Output section of the report
  • Warm-up and reflection answers explain the why, in the student's own words (2 pts): Answers in the report

The checks on the lab page give you feedback; they are not your grade.
