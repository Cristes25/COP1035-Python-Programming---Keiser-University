Lab 6.3a: Whose variable is it? The coffee cart stamp card

Module variables, parameters and temporary variables; scope and lifetime

Estimated time: about 30 minutes. Reading: Fundamentals of Python: First Programs, 3e (Lambert), Section 6.3, Managing a Program's Namespace: Module Variables, Parameters, and Temporary Variables; Scope; Lifetime, pp. 156-158.

You will be able to:

  • Classify each name in a program as a module variable, a parameter or a temporary variable
  • Explain why assigning to a name inside a function creates a temporary variable instead of changing the module variable
  • Pass data in through parameters and back out through return values instead of changing a module variable
