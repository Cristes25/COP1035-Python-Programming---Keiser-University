Lab 6.2: Top-down design: the smart-light command checker

Problem decomposition, a structure chart, responsibility-driven design and bottom-up testing

Estimated time: about 35 minutes. Reading: Fundamentals of Python: First Programs, 3e (Lambert), Section 6.2, Problem Solving with Top-Down Design and Case Study 6-1, pp. 148-156.

You will be able to:

  • Turn each rule of a design into one function, following a structure chart
  • Keep user interaction in main and the decision logic in the functions it calls
  • Test a top-down design bottom up, lowest-level functions first

How to complete it

  1. Open the lab page (6.2.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (lights.py).

How it will be assessed

  • Code meets every requirement (all structure checks pass) (6 pts): Check results in the lab report
  • Test program output matches (2 pts): Output section of the report
  • Warm-up and reflection answers explain the why, in the student's own words (2 pts): Answers in the report

The checks on the lab page give you feedback; they are not your grade.
