Lab 6.1: One algorithm, one place: the food bank hours report

Functions as abstraction: eliminate redundancy, hide complexity, vary the problem instance

Estimated time: about 30 minutes. Reading: Fundamentals of Python: First Programs, 3e (Lambert), Section 6.1, Functions as Abstraction Mechanisms, pp. 145-148.

You will be able to:

  • Replace repeated code with one function that captures a general method
  • Use parameters to supply different problem instances to the same algorithm
  • Build a second function on top of the first instead of copying its loop

How to complete it

  1. Open the lab page (6.1.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (volunteer_hours.py).

How it will be assessed

  • Code meets every requirement (all structure checks pass) (6 pts): Check results in the lab report
  • Test program output matches (2 pts): Output section of the report
  • Warm-up and reflection answers explain the why, in the student's own words (2 pts): Answers in the report

The checks on the lab page give you feedback; they are not your grade.
