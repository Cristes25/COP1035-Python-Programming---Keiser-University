Lab 6.3b: Sensible defaults: progress bars for the study tracker

Required, default and keyword arguments

Estimated time: about 25 minutes. Reading: Fundamentals of Python: First Programs, 3e (Lambert), Section 6.3, Using Keywords for Default and Optional Arguments, pp. 158-159.

You will be able to:

  • Write a function header with required arguments first, followed by default arguments
  • Call a function using its defaults, overriding a default by position, and overriding one by keyword
  • Choose defaults so the most common call is also the simplest

How to complete it

  1. Open the lab page (6.3b.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (progress.py).

How it will be assessed

  • Code meets every requirement (all structure checks pass) (6 pts): Check results in the lab report
  • Test program output matches (2 pts): Output section of the report
  • Warm-up and reflection answers explain the why, in the student's own words (2 pts): Answers in the report

The checks on the lab page give you feedback; they are not your grade.
