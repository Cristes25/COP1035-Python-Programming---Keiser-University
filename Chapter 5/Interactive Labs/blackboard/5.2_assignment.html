Lab 5.2: Pizza night for the programming club

Defining functions: parameters, return, Boolean functions and main

Estimated time: about 30 minutes. Reading: Fundamentals of Python: First Programs, 3e (Lambert), Section 5.2, Defining Simple Functions, pp. 126-128.

You will be able to:

  • Define a function with a header, parameters, a docstring and a return statement
  • Explain the difference between returning a value and printing it, and write a Boolean function
  • Organise a script around a main function that runs only when the file is run as a program

How to complete it

  1. Open the lab page (5.2.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (pizza_night.py).

How it will be assessed

  • Code meets every requirement (all structure checks pass) (6 pts): Check results in the lab report
  • Test program output matches (2 pts): Output section of the report
  • Warm-up and reflection answers explain the why, in the student's own words (2 pts): Answers in the report

The checks on the lab page give you feedback; they are not your grade.
