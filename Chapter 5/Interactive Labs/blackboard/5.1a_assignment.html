Lab 5.1a: The tutoring waitlist

List methods: append, insert, pop, searching safely and replacing elements

Estimated time: about 30 minutes. Reading: Fundamentals of Python: First Programs, 3e (Lambert), Section 5.1, Lists (List Literals and Basic Operators to Sorting a List), pp. 115-121.

You will be able to:

  • Add and remove list elements at either end with append, insert and pop
  • Find an element's position safely by testing with in before calling index
  • Replace the elements of a list with a loop over its indexes, and explain why a loop over the elements can't do it

How to complete it

  1. Open the lab page (5.1a.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (waitlist.py).

How it will be assessed

  • Code meets every requirement (all structure checks pass) (6 pts): Check results in the lab report
  • Test program output matches (2 pts): Output section of the report
  • Warm-up and reflection answers explain the why, in the student's own words (2 pts): Answers in the report

The checks on the lab page give you feedback; they are not your grade.
