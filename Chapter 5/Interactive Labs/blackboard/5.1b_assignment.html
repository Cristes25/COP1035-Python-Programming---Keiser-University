Lab 5.1b: A gradebook that keeps its order

Aliasing and side effects, sort() and None, is versus ==, and tuples

Estimated time: about 30 minutes. Reading: Fundamentals of Python: First Programs, 3e (Lambert), Section 5.1, Lists (Mutator Methods and the Value None to Tuples), pp. 121-125.

You will be able to:

  • Recognise when two variables are aliases for one list and predict the side effect of changing it
  • Copy a list before sorting it, and explain why aList = aList.sort() loses the list
  • Tell object identity (is) from structural equivalence (==), and write a one-element tuple

How to complete it

  1. Open the lab page (5.1b.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (gradebook.py).

How it will be assessed

  • Code meets every requirement (all structure checks pass) (6 pts): Check results in the lab report
  • Test program output matches (2 pts): Output section of the report
