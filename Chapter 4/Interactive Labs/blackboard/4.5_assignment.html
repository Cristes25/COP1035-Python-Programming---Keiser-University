Lab 4.5: A quiz score log that survives

Writing, appending and reading numbers in text files

Estimated time: about 30 minutes. Reading: Fundamentals of Python: First Programs, 3e (Lambert), Section 4.5, Text Files, pp. 100-106.

You will be able to:

  • Write numbers to a text file, converting them to strings and separating them with newlines
  • Read numbers back from a file where they are separated by spaces and/or newlines
  • Choose the right file mode ('w', 'r', 'a') and check that a file exists before reading it

How to complete it

  1. Open the lab page (4.5.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (score_log.py).

How it will be assessed

  • Code meets every requirement (all structure checks pass) (6 pts): Check results in the lab report
  • Test program output matches (2 pts): Output section of the report
  • Warm-up and reflection answers explain the why, in the student's own words (2 pts): Answers in the report

The checks on the lab page give you feedback; they are not your grade.
