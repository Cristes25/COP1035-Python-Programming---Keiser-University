Lab 4.3: A base converter for the network lab

Positional notation, binary, octal and hexadecimal

Estimated time: about 30 minutes. Reading: Fundamentals of Python: First Programs, 3e (Lambert), Section 4.3, Strings and Number Systems, pp. 93-97.

You will be able to:

  • Convert a string of digits in base 2, 8 or 16 to a decimal integer using positional values
  • Convert a decimal integer to any of those bases by repeated division
  • Use a string as a lookup table to turn a value into a digit, including A-F

How to complete it

  1. Open the lab page (4.3.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (bases.py).

How it will be assessed

  • Code meets every requirement (all structure checks pass) (6 pts): Check results in the lab report
  • Test program output matches (2 pts): Output section of the report
  • Warm-up and reflection answers explain the why, in the student's own words (2 pts): Answers in the report

The checks on the lab page give you feedback; they are not your grade.
