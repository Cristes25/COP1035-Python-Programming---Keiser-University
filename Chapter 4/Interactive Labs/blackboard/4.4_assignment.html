Lab 4.4: Cleaning up upload names

String methods: strip, lower, replace, split and the dot notation

Estimated time: about 25 minutes. Reading: Fundamentals of Python: First Programs, 3e (Lambert), Section 4.4, String Methods, pp. 97-100.

You will be able to:

  • Call string methods with dot notation and chain them, knowing each returns a new string
  • Get a file's extension of any length with split('.')[-1], and handle a name with no dot
  • Count words with split(), and explain why split(" ") miscounts

How to complete it

  1. Open the lab page (4.4.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (submissions.py).

How it will be assessed

  • Code meets every requirement (all structure checks pass) (6 pts): Check results in the lab report
  • Test program output matches (2 pts): Output section of the report
