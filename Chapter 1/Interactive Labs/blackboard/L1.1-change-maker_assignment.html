Lab L1.1-change-maker: Change maker

From an algorithm on paper to a working script: input(), int(), subtraction, print()

Estimated time: about 25 minutes. Reading: Ch. 1, section 1.1 (pp. 1–4) and section 1.4, Input, Processing, and Output (pp. 18–19).

You will be able to:

  • Turn the four steps of the book's making-change algorithm into four parts of a Python script
  • Convert keyboard input from a string to an integer with int() before doing arithmetic
  • Print text and a computed value on one line with print(..., ..., ...)

How to complete it

  1. Open the lab page (L1.1-change-maker.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (change_maker.py).

How it will be assessed

  • Input converted with int() (3 pts): Checks C1 and C2
  • Change computed from the variables, correct order (3 pts): Checks C3 and C4
  • Output line in the required form (2 pts): Checks C5 and C6
  • Correct change for all three sales (4 pts): Test program output matches
  • Reflection in own words (3 pts): Answers in the lab report

The checks on the lab page give you feedback; they are not your grade.
