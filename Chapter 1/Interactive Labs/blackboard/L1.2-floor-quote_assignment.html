Lab L1.2-floor-quote: Floor-area quote

Input, processing, output with decimals: float(), *, and print(..., end="")

Estimated time: about 25 minutes. Reading: Ch. 1, section 1.2 (pp. 4–6) and section 1.4, Input, Processing, and Output; Editing, Saving, and Running a Script (pp. 18–20).

You will be able to:

  • Organise a script as input, processing and output, the shape of most useful programs (section 1.4)
  • Choose float() instead of int() when the input can contain a decimal point
  • Control how print separates and ends its output with commas and end=""

How to complete it

  1. Open the lab page (L1.2-floor-quote.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (floor_quote.py).

How it will be assessed

  • Input converted with float() (3 pts): Checks C1 and C2
  • Area and cost computed from the variables (3 pts): Checks C3 and C4
  • Output format: units and no space after $ (2 pts): Checks C5 and C6
  • Correct quote for both customers (4 pts): Test program output matches
  • Reflection in own words (3 pts): Answers in the lab report

The checks on the lab page give you feedback; they are not your grade.
