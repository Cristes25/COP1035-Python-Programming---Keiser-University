Lab L1.3-read-the-error: Read the error

Syntax errors, run-time errors, and what the interpreter does before your first line runs

Estimated time: about 20 minutes. Reading: Ch. 1, section 1.2, Computer Software (p. 6) and section 1.4, Behind the Scenes; Detecting and Correcting Syntax Errors (pp. 20–22).

You will be able to:

  • Read a Python error message: the kind of error, the line, and what Python could not do
  • Fix the syntax errors the book describes: an unexpected indent and an incomplete expression
  • Explain why a syntax error stops a script before any line runs, while a misspelled name fails only when its line is reached

How to complete it

  1. Open the lab page (L1.3-read-the-error.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Use Run to try your code, then run the test program on the lab page; it compares the output for you.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (study_log.py).
