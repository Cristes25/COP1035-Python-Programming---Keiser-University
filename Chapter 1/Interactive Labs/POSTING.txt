Optional: upload index.html together with every lab page in the same folder for a single entry point.

Before posting
  1. Open one lab from Blackboard as a student (Student Preview). Type in the editor and reload: if the code
     is still there, saving works. If the page shows as text or nothing runs, your institution blocks scripts
     in uploaded HTML: host the files on a web server and add links instead.
  2. Create the Assignment, paste the instructions, then set points, due date and attempts in Blackboard.
  3. Never upload the instructor/ folder where students can open it.

Python labs run in the browser. Students need the page opened from a web address (Blackboard is fine) and,
unless you built with --python-runtime, an internet connection the first time (about 12 MB, then cached).
If you built with --python-runtime, upload the runtime/ folder next to the lab pages, keeping its structure.
